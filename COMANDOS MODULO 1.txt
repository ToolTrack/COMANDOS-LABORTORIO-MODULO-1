


 Configuración de parametros de red.
============================================

ip addr
ip route
nmcli connection show


sudo nmcli connection modify ens33 ipv4.method auto
sudo nmcli connection up ens33

sudo nmcli connection modify ens33 ipv4.method manual ipv4.addresses 10.0.0.100/24 ipv4.gateway 10.0.0.1
sudo nmcli connection modify ens33 ipv4.dns "8.8.8.8,8.8.4.4"
sudo nmcli connection up ens33


ip addr
nmcli device show ens33

sudo nmtui


sudo ls /etc/NetworkManager/system-connections/
sudo vi /etc/NetworkManager/system-connections/ens33.nmconnection
sudo nmcli connection reload
sudo nmcli connection up ens33


ip addr
nmcli device show ens33
